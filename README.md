# 🍔 FoodDelivery+

**FoodDelivery+** est une plateforme complète de livraison de nourriture, développée avec une architecture backend robuste en **NestJS** (Node.js + TypeScript) et un frontend en **React** (TypeScript).

---

## 🛠️ Technologies utilisées

### Backend (déjà en place)
-  [NestJS](https://nestjs.com/)
-  MongoDB avec [Mongoose](https://mongoosejs.com/)
-  JWT Authentification & Autorisation
-  RESTful API

### Frontend (à venir)
-  React (TypeScript)
-  Le SCSS
-  Axios / React Query pour la communication API
-  Charts (dashboard restaurant)

---

## 🔑 Fonctionnalités (Backend)

- **Inscription / Connexion**
- **Rôles utilisateurs** : Client / Restaurant / Admin
- **Restaurants**
  - Ajouter / Modifier / Supprimer un restaurant
  - Dashboard avec chiffre d'affaires, nombre de commandes, etc.
- **Plats**
  - Ajouter / Modifier / Supprimer un plat
- **Commandes**
  - Passer commande, voir historique, filtrer par statut
- **Paniers (à finaliser)**
